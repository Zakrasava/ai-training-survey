# Опрос УРП по кадровому порталу

Отдельная форма `/hr/`: 23 вопроса в пяти разделах, пояснения, примеры и ссылки на исходники в корпоративной сетевой папке. Ссылки `file://` могут блокироваться HTTPS-браузером; у каждой есть копирование UNC-пути для Проводника. Исходные PDF/DOC на GitHub не размещаются.

Действующий опрос в корне и его Apps Script не меняются. У кадровой формы собственные файлы, ключ черновика `hr-portal-survey:draft:v1`, новый скрипт и отдельная закрытая таблица.

- Таблица организатора: https://docs.google.com/spreadsheets/d/1PRnjDo_LXdpiYtTd0OvUgVUMe2aDYyPb_MW5mr_gVyc/edit

## Проверки

`node --test hr/tests/*.test.cjs` — правила заполнения, ссылок, восстановления, ошибок, повтора и изменённых ответов; фиксированная схема приёмника, контроль объёма и типов, защита от формул, блокировка, повтор без второй строки, независимость от версии frontend.

Для браузера: из корня запустить `python -m http.server 8768 --bind 127.0.0.1`, затем `python hr/tools/browser-qa.py`. Используется уже установленный Playwright; новые зависимости не нужны. Проверяются размеры 320–1440 px, доступность подписей, черновик, clipboard/storage denial, offline/timeout, ложный ответ об успехе, повтор после перезагрузки и изменения. Все сетевые отправки этой проверки подменяются тестовым приёмником; действующий опрос не затрагивается.

Реальный тест выполняется только через новый `config.js` endpoint, синтетическими ответами с маркером «ТЕСТОВАЯ ЗАПИСЬ». `python hr/tools/verify-google-sheet.py --test-id <UUID>` проверяет закрытые разрешения и единственную запись с этим ID через Drive export, не печатая ответы или credentials.

## Доставка

GitHub Pages публикуется из `main` корня этого репозитория. Новые изменения должны ограничиваться `hr/` и документацией текущей задачи. Перед merge нужны проверки и ревью; до успешной реальной записи в новую таблицу merge и публикация ожидают. После публикации проверить `/hr/`, версию конфигурации и неизменность четырёх файлов исходного опроса.

Новый Apps Script обновляется из `hr/apps-script/`. Его локальный `.clasp.json` исключён из Git. Использовать только новый script/deployment ID из этого раздела; к старому приёмнику не выполнять POST и не менять развёртывание. Google при первом запуске требует личного разрешения владельца своего скрипта.
