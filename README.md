# Опросник перед обучением работе с ИИ

Статическая страница для GitHub Pages. 18 вопросов в четырёх блоках, черновик хранится в браузере, ответы отправляются в Google-таблицу через веб-приложение Apps Script. Без сборки и зависимостей.

## Файлы
- `index.html`, `styles.css`, `app.js` — страница. Вопросы заданы массивом `QUESTIONS` в `app.js`.
- `config.js` — адрес приёмника ответов (`endpoint`). Пока он пуст, страница предупреждает и предлагает скопировать ответы.
- `apps-script/Code.gs` — приёмник: создаёт лист «Ответы», первой строкой пишет заголовки, дальше добавляет строку на каждый ответ.

## Подключение приёмника
1. Создать Google-таблицу. Расширения → Apps Script, заменить содержимое на `apps-script/Code.gs`, сохранить.
2. Развернуть → Новое развёртывание → Веб-приложение. Выполнять от имени: я. Доступ: все. Развернуть, разрешить доступ.
3. Скопировать URL вида `https://script.google.com/macros/s/…/exec` и вставить в `config.js` в поле `endpoint`.
4. Проверка: открыть URL в браузере — должно вернуться `{"ok":true,…}`. Отправить тестовый ответ со страницы — в таблице появится строка.

## Локальный просмотр
Открыть `index.html` в браузере. Для проверки отправки нужен настроенный `endpoint`.
