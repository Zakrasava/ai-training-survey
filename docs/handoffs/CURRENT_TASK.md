# Онлайн-опрос для УРП

- Задача: отдельный опрос по 23 уточнениям к кадровым материалам с записью в новую Google-таблицу.
- Этап: 8 — опубликовано, проверки рабочего адреса завершены.
- Ведущий: Codex.
- Ветка: main; реализация feature/hr-portal-survey-20261008 влита через PR #1.
- Артефакты: hr/, docs/prototypes/hr-survey.html, docs/design-system/hr-survey.md.
- Следующее действие: получить ответы УРП; реализация кадрового портала в эту задачу не входит.

## Критерии приёмки

- Новый адрес /hr/; существующий опрос, его файлы, ключи черновика и приёмник неизменны.
- Все К01–К23, пять разделов, пояснения и примеры, ссылки на исходники в указанной корпоративной папке и копирование сетевых путей.
- Решения владельца: первый выпуск всех страниц, шести ЛНА и двух заявлений; компьютер и телефон; макеты УРП обязательны. Эти решения не запрашиваются заново.
- Черновик, прогресс, доступность с клавиатуры, мобильная вёрстка, понятные ошибки и повторная отправка без дублирования.
- Отдельный Apps Script и закрытая таблица; только подтверждённое сохранение означает успех. Исходные PDF и документы работников не публикуются.
- Проверки правил и приёмника, браузерные состояния, тестовая запись в новую таблицу, ревью, PR, публикация и проверка обоих адресов.

## Решение по реализации

Статические HTML/CSS/JS без новых зависимостей, оформление по действующему опросу. Корпоративные исходники остаются на файловом сервере; HTTPS-браузер может блокировать file-ссылки, поэтому у каждой есть копирование пути для Проводника. Ответы — правила, роли и ссылки, без кадровых персональных данных. Приёмник использует фиксированную схему и блокировку, проверку значений, защиту от формул и идентификатор повторной отправки.

## Проверки и доставка

16 проверок node:test прошли. Браузер Chromium: 23 вопроса, адаптивность 320/360/390/768/1440 px, восстановление черновика, валидация, ручное копирование при отказе Clipboard, offline/timeout, повтор после reload с тем же ID, новая версия после изменения и сохранность старого ключа опроса. Проверено оформление по скриншотам. Физические устройства и корпоративный файловый сервер не проверены.

Созданы независимые Apps Script и таблица; у таблицы только разрешение владельца. Веб-приложение настроено ANYONE_ANONYMOUS / USER_DEPLOYING. Первичное разрешение владельца получено, анонимный GET возвращает ok:true/service:hr-portal-survey.

Независимое техническое ревью Claude выполнено на обезличенном снимке кода: тексты кадровых вопросов, сетевые пути, документы и ответы не переданы. Подтверждённые замечания исправлены: понятные сообщения по кодам ошибок, повтор/отмена правки без смены ID, исключение версии frontend из контрольной суммы, журналирование только кодов ошибок, проверка типов и согласование валидации клиента/приёмника. Контрольное ревью исправлений: PASS, нет замечаний, блокирующих выпуск. Незначительные рекомендации по тестам также учтены.
